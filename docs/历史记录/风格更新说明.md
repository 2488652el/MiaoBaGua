# 赛博卦摊 · 新中式暗色风格更新

## 更新时间
2026-09-28

## 设计理念
将传统易经占卜的文化底蕴与现代暗色系 UI 相结合，创造出既神秘又高级的视觉体验。

---

## 核心配色方案

### 背景层次
```css
--bg-ink: #0f1419        /* 深墨色背景 */
--bg-paper: #1a1f2e      /* 宣纸质感 */
--bg-elevated: #242938   /* 浮起卡片 */
--bg-surface: #2a3142    /* 输入框表面 */
```

### 强调色
```css
--gold: #d4af37          /* 金色 - 主要装饰 */
--gold-dim: #8b7831      /* 暗金色 */
--cinnabar: #c1440e      /* 朱砂红 - 卦名和强调 */
--cinnabar-deep: #8b2500 /* 深朱砂 */
--jade: #3d7f7a          /* 玉色 - 成功状态 */
--jade-bright: #5fa399   /* 亮玉色 */
```

### 文本层次
```css
--text-primary: #e8e6e3   /* 主文本 */
--text-secondary: #b8b5b0 /* 次要文本 */
--text-muted: #6b7280     /* 提示文本 */
--text-dim: #4b5563       /* 辅助文本 */
```

## 主要视觉改进

### 1. 顶部栏
- **深色渐变背景**：从 `#1a1f2e` 到 `#242938`
- **金色底边**：3px 实线 + 流动光效动画
- **印章图标**：
  - 金色边框带双层描边
  - 旋转 -4° 增加手工感
  - 呼吸发光动画（2秒循环）
- **品牌名称**：金色渐变文字（`#d4af37` → `#f9f3d9`）
- **状态指示**：青色圆点带脉冲动画

### 2. 卦卡（直播组件）
- **圆角矩形**：`border-radius: 3%`（相对尺寸）
- **金色内边框**：1px，透明度 0.3
- **深色外阴影**：模拟悬浮效果
- **六爻显示**：
  - 金色横向渐变（中间亮两侧暗）
  - 圆角矩形（`rx="2"`）
  - 动爻用朱砂红（`#c1440e`）并带发光
  - 出现动画：0.6秒弹性缩放 + 淡入
- **卦名**：
  - 朱砂红色，极粗书法字体
  - 多层文字阴影和发光效果
  - 2秒呼吸发光动画

### 3. 骰子动画（重点优化）
#### 视觉增强
- **渐变表面**：每个骰子面使用线性渐变
  - 金色骰（上卦）：`#f4e4a6` → `#d4af37`
  - 青色骰（下卦）：`#7ec4bc` → `#3d7f7a`
  - 朱砂骰（动爻）：`#e76f51` → `#c1440e`
- **发光滤镜**：文字和点数带高斯模糊发光
- **增强阴影**：drop-shadow 增加立体感

#### 动画改进
- **入场动画**（0.5秒）：
  - 从缩小 + 上移状态弹入
  - 三个骰子依次延迟（0s / 0.1s / 0.2s）
- **翻滚动画**（0.45秒循环）：
  - 上下位移 + 旋转 + 缩放组合
  - 三个骰子相位错开，形成错落感
  - 青色骰反向运动增加对比
- **定格动画**（0.4秒）：
  - 弹性缓动（`cubic-bezier(0.34, 1.56, 0.64, 1)`）
  - 轻微反弹效果模拟真实落地

### 4. 按钮和表单
#### 主按钮（摇卦）
- **渐变背景**：朱砂红到深朱砂
- **内发光**：顶部白色高光（透明度 0.2）
- **悬停**：向上位移 2px + 加深阴影
- **悬停高光**：渐变叠加层淡入

#### 主题选项卡
- **未选中**：深色背景，金色细边框
- **悬停**：金色径向渐变叠加（透明度 0.05）
- **选中状态**：
  - 金色渐变背景
  - 金色边框增强
  - 向上浮起 2px
  - 金色外发光

#### 输入框
- **深色背景**：`#2a3142`
- **金色边框**：默认透明度 0.2
- **焦点状态**：边框变实 + 3px 金色外发光

### 5. 卦象解读区域
- **卦对展示**：
  - 白色细边框卡片
  - 悬停时边框加深 + 阴影增强
  - 变卦用青色渐变背景
- **六爻图标**：
  - 金色填充
  - 发光滤镜（drop-shadow）
- **体用关系强调**：
  - 朱砂红粗体书法字
  - 文字阴影和发光
  - 左侧金色分隔线

### 6. 历史记录
- **列表项**：
  - 细金色分隔线（透明度 0.1）
  - 悬停时：金色背景叠加 + 左右扩展 8px
- **卦名**：19px 粗体书法字
- **右侧箭头**：悬停时变金色

## 动画时序

### 关键动画参数
```css
/* 入场 */
animation: 0.5s cubic-bezier(0.34, 1.56, 0.64, 1)

/* 翻滚 */
animation: 0.45s cubic-bezier(0.45, 0.05, 0.55, 0.95) infinite alternate

/* 定格 */
animation: 0.4s cubic-bezier(0.34, 1.56, 0.64, 1) forwards

/* 呼吸发光 */
animation: 2s ease-in-out infinite alternate
```

### 持续动画
1. **顶部金边流光**：3秒线性无限循环
2. **印章发光**：2秒交替呼吸
3. **卦名发光**：2秒交替呼吸
4. **状态指示脉冲**：2秒淡入淡出
5. **空状态浮动**：3秒上下浮动

## 无障碍支持

### 对比度
- 主文本 vs 背景：14.2:1（WCAG AAA）
- 金色强调 vs 深背景：7.8:1（WCAG AA）
- 朱砂红 vs 深背景：5.2:1（WCAG AA）

### 减少动画模式
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
  }
}
```

## 技术亮点

### 1. 纸张噪点纹理
```css
background-image:
  radial-gradient(circle at 20% 50%, rgba(212, 175, 55, 0.03) 0%, transparent 50%),
  radial-gradient(circle at 80% 20%, rgba(61, 127, 122, 0.03) 0%, transparent 50%);
```

### 2. 动态渐变生成
每个骰子/六爻组件使用 `useId()` 生成唯一 ID，避免 SVG 渐变冲突。

### 3. 性能优化
- 使用 `will-change` 提示浏览器优化
- CSS `contain` 限制重排范围
- 动画使用 `transform` 和 `opacity`（GPU 加速）
